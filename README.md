## 📖 Overview
This project implements a full-stack financial analysis pipeline, integrating automated data extraction (ETL), deep learning-based forecasting, and interactive business intelligence dashboarding.

## 🚀 Key Features
- **Data Pipeline:** Automated ETL using `yfinance` API with robust cleaning and normalization.
- **Model Architecture:** Machine Learning model using Scikit-learn for time-series forecasting.
- **Data Integrity:** Implemented strict time-based splitting to prevent data leakage.
- **Business Intelligence:** Interactive Tableau dashboard for visualizing trends and model performance.
